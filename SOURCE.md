# Source snapshot

The source/ directory contains the exact v0.2.78 C# implementation and bundled standard-profile JSON used for the verified build. The plugin version is 0.2.78. No gameplay changes were made after in-game verification.

This is a source snapshot, not a standalone build kit. Proprietary game/Unity/Spine assemblies, game-derived sprite resources, the local build project and developer paths are intentionally excluded. PNG resources remain embedded in the released plugin, as in the previous release. Building requires a locally configured .NET Framework 4.7.2 / BepInEx 5 project, appropriate game references and the original embedded resources. No third-party source or game decompilation is included.
